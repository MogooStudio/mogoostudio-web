# 首页向下滚动动效：四套高清分镜

设计日期：2026-10-16。首轮基于现有 MogooStudio 首页交付四套静态分镜。用户随后选择 **A+B 分段组合**，现已接入实际首页；实现、评审和验证边界见 [IMPLEMENTATION.md](./IMPLEMENTATION.md)。以下四个方向保留为最初的设计档案，静态分镜本身不能证明真实滚动、交互或性能表现。

## 任务与共同约束

用户来首页了解工作室和作品，主动作仍是“探索作品”、点击产品图预览，以及使用已有真实产品链接。保持奶油白背景、圆润粗黑字体、珊瑚红主操作，以及浅绿、奶橙、冰蓝的产品配色。Hero 沿用红黄青积木、白球、篮球、笔记本与铅笔的暖光静物，不另造视觉主题。

保持导航 → Hero → 精选作品 → 拼一页 → 你行你上啊 → 两款游戏 → 工作室价值 → 页脚的顺序。桌面每款产品仍为左图右文；窄屏可以上图下文。介绍内部保持四层：图标与名字（图标不明确则省略）→ 一段简述 → 类型/平台与状态 → 真实产品链接（没有则省略）。不增加标语、功能清单、重复名称或虚构链接；截图预览不能替代产品链接。英文、简体中文、繁体中文保留相同结构。

## 四套独立候选

### A · 景深拉远

主角是现有首屏静物。约 100vh 的滚动距离中，静物整体由 1 缩至 0.82，标题向上退出；精选作品在收束后的画面下方接入。用整体缩放建立景深，避免把单张照片误当成已具备的独立物体图层。

| 分镜 | 画面与动作 |
| --- | --- |
| 开始 · 0% | 保留大标题和完整静物构图，介绍与探索按钮稳定可读。 |
| 中段 · 50% | 静物约 0.91；大标题明显上移，正文和按钮保持原尺寸；精选作品标题从下缘进入。 |
| 结束 · 100% | 静物停在 0.82，首款作品接到视觉中心；标题退出，避免留下空白舞台。 |

窄屏保留整体拉远，缩短至约 80vh，静物以主体裁切，结束缩放可收至 0.85。减少动态效果时取消固定和缩放，首屏与作品按普通文档流排列。复杂度：**中**；主要使用现有整图与版面，需校准三语标题退出和下一区块交接。

分镜图片：[A-depth.png](./A-depth.png)。

### B · 相纸拼合

主角是拼一页已有的两张真实相纸与编辑器截图。约 100vh 内，相纸从散开到靠拢，最终与手机/拼图组成稳定的一组；右侧介绍始终保持位置和字号，停稳后再离场。

| 分镜 | 画面与动作 |
| --- | --- |
| 开始 · 0% | 两张相纸分列手机两侧，角度稍开，留出完整产品介绍。 |
| 中段 · 50% | 相纸朝手机靠拢并轻转，前后遮挡保持自然；手机稳定为中心，文字不随相纸移动。 |
| 结束 · 100% | 相纸落至现有扇形构图，阴影收稳；整组保留一段阅读区间，再正常进入下一款产品。 |

窄屏改为上图下文，相纸活动限制在图片区，约 80vh，不跨越文字。减少动态效果时直接显示结束构图。复杂度：**中低**；相纸与手机已有独立元素，可复用真实素材，重点是约束遮挡和窄屏边界。

分镜图片：[B-paper-v2.png](./B-paper-v2.png)。第一版保存在 B-paper.png；第二版修正了右侧段落换行与视口边界。

### C · 作品叠页

以浅绿拼一页 → 奶橙你行你上啊 → 冰蓝/浅杏双游戏卡的竖向叠页交接形成作品展台，每张约 80vh。每款介绍始终左图右文，完整可读后，下一页才从下方接替；不是横向轮播，也不把文字压成装饰。

| 分镜 | 画面与动作 |
| --- | --- |
| 开始 | 拼一页完整露出，后续作品只在下缘露出轻薄的色面。 |
| 中段 | 你行你上啊向上接替，前页轻退至背景；当前页的图与四层信息全部可读，下一页不遮正文。 |
| 结束 | 你行你上啊完整落位，前页只剩背后的薄边；底部露出下一组游戏的冰蓝边缘。继续滚动时，两款游戏按原顺序展示并保留真实链接，随后进入价值区。 |

窄屏将双游戏卡拆为顺序纵排，每款分别留足阅读空间，约 60–80vh；当前卡片高度超过屏幕时先自然滚完，再交接。减少动态效果时取消固定和叠压，按原顺序展开所有卡片。复杂度：**高**；涉及可变文案高度、层级、可点击区域及移动端的完整阅读。

分镜图片：[C-stack-v2.png](./C-stack-v2.png)。第一版保存在 C-stack.png；第二版强化了前后页的实际叠压关系。

### D · 弹跳接力

从 Hero 的白球/篮球取品牌动作，在约 120vh 的叙事段内沿画面边缘弹跳，承接游戏实机与价值区。球体是清晰的前景主角，利用跃起、落点压缩与回弹形成镜头变化；正文保持原位，路径避开标题、介绍、标签和按钮。

| 分镜 | 画面与动作 |
| --- | --- |
| 开始 · 0% | 白球从首屏构图边缘起跳，第一处落点引向作品区；不另加贯穿正文的装饰线。 |
| 中段 · 50% | 同一颗白球在外侧边缘经过游戏实机，落点带出截图主体；球的路径不跨越文字。 |
| 结束 · 100% | 白球在价值区之后的珊瑚红页脚边缘收稳；三个价值图标依次出现，正文正常阅读。 |

窄屏把路径压缩到图片区和外缘，减少横向跨越，约 90vh；触控区域不被球遮挡。减少动态效果时取消球的路径演出，保留静态主视觉与实机。复杂度：**高**；当前 Hero 是单张照片，需要额外分离球体并修复底图，设计图中的接力不代表已有可用分层资产。

分镜图片：[D-bounce.png](./D-bounce.png)。

## 各区块的出场设计

这些是选定主叙事后的辅助节奏，每个区块只触发一次，回滚不反复飞入；单区块控制在 900ms 内。候选之间避免机械地叠加全部演出。

| 区块 | 建议出场与目的 |
| --- | --- |
| Hero | 主视觉先建立，标题按行由遮罩中露出，其余晚 40–80ms 跟上；A 的滚动阶段另按滚动进度控制。 |
| 精选作品标题 | 从下缘短距离揭开，与首屏退出衔接，不整段淡入上移。 |
| 拼一页 | 相纸轻转落桌、先快后慢；B 将这一材质动作延展成主叙事。 |
| 你行你上啊 | 两张实机截图依次落位，整组过冲不超过 1–2%，保留软陶游戏的重量感。 |
| 两款游戏 | 截图从主体方向揭开并由 1.08 收至 1，第二卡晚约 60ms；作品介绍保持稳定。 |
| 工作室价值 | 图标先到，文字随后直接清晰出现；三个图标沿阅读顺序接力，D 由球的最终落点引出。 |
| 页脚 | 珊瑚红色面从下缘揭开，文案和链接到位后保持静止。 |

## 三处基础反馈建议

1. **主操作**：“探索作品”按下立即缩至约 0.97，松开回到原位；箭头轻移 3–4px，点击仍按原锚点进入作品。
2. **状态切换**：点击产品图后，预览框从该图方向短促进入；下一张从右进入、上一张从左进入，关闭回到原位与焦点。约 200–300ms，快速操作可打断。
3. **首次进入**：Hero 主视觉先到，标题、介绍、按钮按阅读顺序跟进，间隔 40–80ms，总长不超过 600ms；仅首次进入播放。

减少动态效果时上述位移、缩放和过渡直接到位，仍保留清晰的按下、聚焦和选中状态。这三项是设计建议，本轮没有制作运行证据。

## 推荐与实现边界

推荐 **A + B 分段组合**：A 让现有暖光静物承担工作室的整体气质，B 用真实相纸说明拼一页的用途，两个主角来自现有素材、各有独立阅读停顿。其余作品采用短促的一次性出场，整体节奏较容易控制。C 更适合把作品浏览做成展厅，开发和窄屏校准较多；D 最活泼，但需要新增分层素材，注意力也更容易离开产品内容。

实现时区分两类动作：主叙事与滚动位置一一对应，停滚即停、回滚倒放；辅助区块进入只播放一次。候选落地可使用成熟的 GSAP / ScrollTrigger 能力，不接管原生滚动，不隐藏滚动条。实际距离需根据文案和视口调整，本说明中的 vh 为设计目标。

当前首页已有一次性入场：Hero 文案上移 10px、450ms；产品进入 20% 视口后上移 12px、透明度 0.75 → 1、450ms；价值行从两侧裁切 6% → 0 并淡入，触发后取消观察。见 [StudioHome.astro](../../../src/components/StudioHome.astro) 第 123–139 行。布局、悬停、画廊进入与减少动态效果的当前规则见 [playground.css](../../../src/styles/playground.css) 第 6–33、117–178、199–224 行。
