# A 居中胶囊：接入与验证

2026-10-16，用户选择 A 后接入。与居中标题、圆润字形和珊瑚红主色保持一致。默认全部，显示实际节点计算的全部 4、游戏 3、小程序 1；不增加空分类、状态筛选或搜索。

## 实现

- `StudioHome.astro` 在标题与作品之间增加原生按钮分类导航，并标记各产品类型。英、简、繁文案同步。产品图片、介绍顺序、状态及唯一已确认的 App Store 地址保留。
- `work-categories.ts` 管理隐藏状态、数量、`aria-pressed` 与结果播报。禁用 JavaScript 时控件隐藏，全部作品直接可读。英语标签按内容分配宽度，320px 下数量放到标签下方，字体仍为 19px 粗体。
- 珊瑚红底板与白字合为一个视觉层，用 240ms clip-path 同步移动；新结果 180ms 透明度过渡。快速切换会取消上一段结果过渡。键盘操作立即响应；减少动态效果时禁用这些过渡。
- 作品动效独立使用 GSAP context。分类切换回收旧场景，只对可见产品重建，刷新测量并恢复滚动位置。首屏 A 景深场景不随分类重建；B 相纸场景在拼一页重新显示后继续跟随滚动。
- 直达隐藏产品的锚点会先恢复全部再定位。普通分类切换不改 URL fragment。图库继续使用现有原生 dialog、方向切换、Esc 与关闭后焦点恢复。
