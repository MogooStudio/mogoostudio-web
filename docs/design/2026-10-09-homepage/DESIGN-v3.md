# MogooStudio 首页设计 V3

2026-10-09。本版取代 V2 的视觉与未来平台板块决策；工作室涵盖软件、应用与游戏的定位保持。

用户反馈：不需要强调 macOS、Windows、微信小程序／小游戏的未来方向；顶部不要假窗口、图标等示意性大图，要生成更真实的图。

## 已完成

- 完全删除“从桌面，到掌心”板块、未来语态、平台图标墙。平台仅作为当前作品的具体信息出现。
- 三套完整首页的主视觉改为摄影质感场景；去掉悬浮窗口、巨型光标、塑料应用图标。
- A 为日光木桌与自然物件，B 为暮色下台灯照亮的工作台，C 为笔记本、纸张、键盘与咖啡的自然光近景。
- 第二轮精修移除物件上的宣传字样；C 修正标题和说明跨入照片的问题，保持文字与照片的清楚边界。
- 保留 Minimalist Breakout 的 iOS / 已上线 / App Store 信息，以及 Flappy Ball Hop 的即将推出状态；无虚构新软件。

推荐 C：摄影氛围与作品阅读保持平衡，适合长期展示不同产品。A 更温暖亲和，B 更有夜间创作气氛。

## 检查与边界

主 Agent 已直接查看三套最终完整图，检查文字、图文边界、已删除区域及产品状态。未独立评审，不提供虚构评分。主视觉由内置 imagegen 生成摄影风格场景，不是用户真实工作室的实拍照片；游戏画面仍为生成宣传视觉。

本轮只修改设计交付物，没有改业务代码。静态图不包含真实筛选、下载交互、移动端和动效，因此未做相应测试或录屏。动效落地建议仍是按钮按压、筛选淡入与链接箭头反馈；照片可轻微裁切推进，作品区分段出现。本轮无动态证据。
