# MogooStudio 首页视觉设计

日期：2026-10-09

## 范围与依据

三套完整桌面首页高保真静态设计图。用户明确要求真实设计图，直接制作完整视觉方案，跳过风格卡片。使用内置 imagegen 生成，没有修改 Astro 页面或业务代码。

依据：仓库 README、首页、翻译文案及两款游戏的截图。MogooStudio 是独立手游工作室，主张「小游戏。大乐趣。」。Minimalist Breakout 当前有 App Store 下载入口；Flappy Ball Hop 当前为即将推出。

首要任务：认识游戏、理解玩法、找到可下载作品。次要任务：了解工作室与获取支持。信息结构参考 [Playdead 官网](https://www.playdead.com/) 的作品与支持优先导航；视觉从本项目砖块、球、篮圈推导。未进行标杆站视觉截图比对。

## 方向

| 方案 | 版式与视觉 | 理由 |
| --- | --- | --- |
| A 玩具乐园 | 奶油白、珊瑚红、青色，圆润大字，居中立体游戏物件，双游戏展台 | 推荐；明亮触感传达休闲游戏的轻松与简单乐趣 |
| B 深夜街机 | 炭黑、酸柠黄，满幅游戏舞台，横向作品章节 | 突出动作、反馈与游戏本身的存在感 |
| C 游戏刊物 | 纸白、朱橙、黑色，超大字、不对称作品网格、细分隔线 | 强调独立创作气质与作品阅读顺序 |

## 文案与状态

保留游戏全名、上线状态、下载动作、支持和法律入口。删除原首页 2 / 1 / ∞ 统计条及重复宣传文字。不增加未经验证的玩家数、评分、奖项或评价。生成的玩法艺术用于宣传视觉，不能当作逐像素真实游戏截图。

## 交付边界

本轮是可直接查看的位图设计稿，不是可编辑 Figma 文件或已实现网站。未做移动端、交互测试、动效录制或生产构建。独立方向探索轮未进行独立评审，不提供评分；由主 Agent 直接检查输出。

后续实现建议：按钮按下缩放至 0.97（120ms）；链接箭头横移 4px（180ms）；内容展开淡入上移 12px（240ms）。A 可用小球轨迹把主视觉带入游戏展台；B 用球的轨迹连接游戏章节；C 用大字标缩进导航。以上动效未实现，无动态证据。落地时应复用仓库原始截图，并以真实 HTML 排版文字。
