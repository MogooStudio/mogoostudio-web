# MogooStudio：独立数字产品工作室

2026-10-09 · V2 · 本文取代 V1 的游戏工作室定位，V1 留作历史对照。

## 已确认定位

用户明确：官网后续不仅展示游戏，还包含 macOS / Windows 软件、微信小程序与小游戏。网站主语应是独立创作工作室，作品允许跨类别与平台。主张提案：做点有用的，也做点有趣的。

首页主任务：理解品牌范围、按类型浏览作品、判断平台与上线状态、进入产品或下载入口。作品区类型为全部 / 软件 / 游戏 / 小程序；平台是独立属性，微信小游戏归游戏类型、微信平台。产品可支持多个平台，各下载入口独立标识，不能用一个通用下载按钮掩盖平台差别。

当前只展示仓库已有的 Minimalist Breakout（iOS，已上线）和 Flappy Ball Hop（即将推出）。未来方向区域包含 macOS、Windows、微信小程序、微信小游戏，明确用未来语态，无软件名称、虚假下载按钮或二维码。当前空的软件与小程序分类落地时应呈现简洁空状态，实际产品加入后显示作品；本轮静态稿未绘制筛选后的空状态。

## 三套视觉

- A 温暖数字工坊：奶油白与珊瑚色，立体窗口、光标和品牌方块成为主视觉；游戏球体退为小元素。适合亲和、轻松的品牌。
- B 深色产品实验室：深色窗口与光标装置，横向产品章节与荧光色强调；从街机气氛转向产品制作。
- C 独立作品目录：白底、朱橙、超大字与作品网格。新版优先推荐 C，理由是品牌表达不依赖特定游戏素材，持续新增桌面软件和微信作品更自然。

本轮交付三套完整静态设计图，未修改 Astro 业务代码，未实现筛选、跨平台下载、移动端或动效，未跑业务测试。动效建议：按钮按压反馈、分类切换淡入、作品链接箭头位移；滚动叙事可由品牌窗口收束为作品区域，不再把弹球轨迹作为全站叙事。以上均未实现，无动态证据。
